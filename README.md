# dox-u

Проект на rost-rs (фреймворк), возможно как отдельная страница блога.
По SSR отдаёт все данные, которые о посетителе видит сервер (IP,
заголовки, геолокация по IP и т.д.), затем клиентский компонент
дополнительно собирает всё, что можно узнать на уровне JS без
запроса разрешений (canvas/WebGL fingerprint, шрифты, часовой пояс,
разрешение экрана и т.д.). Экспериментально пытается поймать
реальный IP через TURN-сервер (обход VPN/прокси через WebRTC).
Данные не собираются и не хранятся — только показываются
пользователю в моменте, как демонстрация того, что видно о нём
без каких-либо разрешений.
